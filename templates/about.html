What TrustLens does

A local educational aid for thinking carefully about suspicious messages and destinations—not a security verdict.

How analysis works

TrustLens applies deterministic string-based heuristics to text, URL structure, sender text, and social-engineering language. Each detected indicator names its category, severity, reason, and point contribution. A small deterministic bonus reflects signals appearing across multiple categories; the result is capped at 100.

Important limitations

  • Submitted URLs are parsed as strings only. No DNS, browsing, redirects, page content, or external reputation checks are performed.
  • Sender details are not independently verified. A sender/domain match does not prove authenticity.
  • Heuristics can miss real threats and flag harmless content. A low score never guarantees safety.
  • Analysis history stores a compact preview (up to 240 characters) and structured results; it does not store the full submitted form.
  • This tool is not a substitute for organizational security processes or professional incident response.
⌑

Designed to stay local

Analysis runs in this Flask application using Python and SQLite. No external analysis API or submitted-link fetch is used.

Safer habits

Verify urgent requests via a known-good contact channel. Never share passwords or one-time codes in response to an unexpected message.
